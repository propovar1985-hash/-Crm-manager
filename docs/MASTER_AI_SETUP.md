# MASTER AI — подключение бесплатного облачного провайдера

## Что нужно создать
1. Бесплатный аккаунт Cloudflare.
2. В Cloudflare открыть Workers AI и создать API Token с разрешением **Account → Workers AI → Read**.
3. Скопировать Account ID и API Token. Не отправлять токен в чат, не добавлять его в GitHub и не вставлять в HTML/JavaScript.
4. В Supabase открыть Edge Functions → Secrets и добавить:
   - `CLOUDFLARE_ACCOUNT_ID` — Account ID Cloudflare.
   - `CLOUDFLARE_API_TOKEN` — токен Cloudflare.

## Публикация backend-функции
Из локальной копии репозитория, после переключения на ветку `feature/master-ai-free-cloud`:

```bash
supabase login
supabase link --project-ref zxgkodaeynzcprhnymee
supabase functions deploy master-ai --project-ref zxgkodaeynzcprhnymee
```

В Edge Function используются стандартные переменные Supabase `SUPABASE_URL` и `SUPABASE_ANON_KEY`. Service-role key для AI-чата не используется.

## Включение интерфейса
Файл `index.html` в этой ветке подключает `master-ai.js`. После проверки и слияния ветки в `main` GitHub Pages опубликует интерфейс согласно настройкам репозитория.

## Проверка
1. Войти в CRM.
2. Открыть кнопку «MASTER AI» в правом нижнем углу.
3. Отправить короткий тестовый вопрос.
4. Убедиться, что ответ получен от `@cf/zai-org/glm-4.7-flash`.
5. Выйти из CRM и убедиться, что кнопка помощника скрыта.
6. Проверить вызов без Authorization: ожидается HTTP 401.
7. Проверить Cloudflare Workers AI usage: бесплатная квота не должна превышаться.

## Бесплатная квота и защита от расходов
Workers AI Free предоставляет опубликованную квоту 10,000 Neurons в сутки. Если квота или ёмкость модели исчерпана, функция возвращает ошибку. Платный fallback и автоматическое повышение тарифа не реализованы.
Квота, доступность моделей и условия бесплатного плана могут меняться. Не включать Workers Paid и не привязывать платёжный метод, если принципиально важно сохранить расходы равными нулю.

Supabase Free также имеет лимиты и может приостанавливать неактивный проект. AI не сможет работать, если сам проект Supabase приостановлен.

## Данные и конфиденциальность
На начальном этапе в Cloudflare отправляются только сообщения текущего чата; запросы к таблицам CRM не выполняются. Не вставляйте в чат пароли, платёжные данные, токены и лишние персональные сведения клиентов.
Cloudflare описывает Workers AI как сервис с нулевым хранением данных для обработки контента модели. Перед передачей клиентских данных всё равно нужно отдельно проверить применимые условия и внутренние требования к обработке персональных данных.

## Ограничения текущей версии
Это безопасный первый этап: облачный чат доступен после настройки Cloudflare и публикации Edge Function, но пока не читает клиентов, заказы, календарь, расчёты, поставщиков или производственные таблицы. Для подключения каждого раздела потребуется инвентаризировать таблицы, поля, RLS-политики и действующие функции CRM, затем добавить узкие серверные инструменты. Изменения данных будут только через подтверждение пользователя.
