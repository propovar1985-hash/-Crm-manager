CRM «Мастер мебельщик» — комплект расширения
================================================

ВАЖНО
-----
Это комплект модулей для текущей CRM, а не законченная реализация всех функций из большого ТЗ.
Существующие Supabase URL/key, авторизация, таблицы clients и crm_deals не заменяются.
Сделайте резервную копию проекта и БД до установки.

ФАЙЛЫ
-----
crm-enhancements.js       Поиск и избранное (уже установлен в репозитории; включён для полного комплекта)
crm-orders.js             Карточки заказов
crm-production.js         Этапы производства и контроль качества
crm-rest.js               Базовые задачи, сервисные обращения, каталог и инструкции
supabase-all-modules.sql  Единая SQL-миграция для новых таблиц
supabase-orders.sql       Исходная миграция заказов (для справки)
supabase-production.sql   Исходная миграция производства (для справки)
supabase-rest.sql         Исходная миграция остальных таблиц (для справки)

ПОРЯДОК УСТАНОВКИ
-----------------
1. Сделайте резервную копию Supabase и GitHub-репозитория.
2. В Supabase SQL Editor выполните ОДИН РАЗ файл supabase-all-modules.sql.
3. Загрузите в корень репозитория рядом с index.html:
   crm-orders.js
   crm-production.js
   crm-rest.js
4. В index.html оставьте существующие подключения и добавьте перед </body>
   в таком порядке:

   <script src="./crm-enhancements.js"></script>
   <script src="./crm-orders.js"></script>
   <script src="./crm-production.js"></script>
   <script src="./crm-rest.js"></script>

5. Сохраните index.html (Commit changes).
6. Откройте CRM, обновите страницу. Проверьте вход, клиентов, сделки и новые разделы.

НЕ ВКЛЮЧЕНО / НУЖНЫ ОТДЕЛЬНЫЕ ИНТЕГРАЦИИ
----------------------------------------
- Реальная отправка Push, Telegram, Email и сообщений WhatsApp/Instagram.
- Клиентский кабинет и защищённые персональные ссылки.
- ИИ-анализ LiDAR/3D и ИИ-проверка чертежей.
- Прямая интеграция с БАЗИС-Мебельщик.
- WebAuthn/Face ID/Windows Hello.
- Офлайн-синхронизация, резервное копирование в отдельное хранилище.
- Полноценные шаблоны договоров/PDF/Excel, электронные подписи.
- QR-коды, геолокация выездных сотрудников и рейтинг сотрудников.
- Полный журнал аудита, корзина восстановления и тонкие роли/RLS по организациям.
- Загрузка файлов/фото в Supabase Storage: в текущем наборе предусмотрены URL-поля, но не настроено хранилище.

Безопасность: политики в SQL дают всем аутентифицированным пользователям проекта доступ к общим данным новых таблиц. Это базовая схема для одной команды, не разграничение доступа по сотрудникам/организациям. До рабочего запуска необходимо настроить ограничения RLS под реальные роли.

ПРИМЕЧАНИЕ
-----------
В карточке заказа стоимость и статус оплаты используются только для контроля договора.
Отдельный финансовый модуль, склад, сдельная оплата и карта распила не добавляются.


ДОПОЛНЕНИЕ: КАТАЛОГ ПРАЙСА ДЛЯ ПРОСЧЁТНИКА
------------------------------------------
Для подключения материалов, облицовки, фурнитуры, купе, лицевой фурнитуры,
крепежа, света, комплектующих и работ из пользовательской книги выполните
в Supabase SQL Editor файл supabase-estimate-user-catalog.sql ОДИН РАЗ.
Миграция создаёт отдельный каталог, импортирует позиции и исходные цены,
а также добавляет ссылку на выбранную позицию в строки сметы.

После выполнения миграции откройте раздел «Расчёты» и обновите страницу.
В деталировке выбирается листовой материал из каталога; цена листа
пересчитывается в цену за м² для расчёта площади детали. В позициях сметы
доступен каталог по разделам. Цену после выбора можно изменить вручную;
в сохранённой смете фиксируется выбранная позиция и цена на момент расчёта.

Если SQL-миграция не выполнена, каталог не загрузится, но остальные разделы
CRM продолжат работать. Цены из исходной книги перенесены как стартовые
значения и требуют проверки перед коммерческим предложением.
